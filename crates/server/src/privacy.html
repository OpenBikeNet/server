OpenBikeNet server · Privacy

OpenBikeNet is a relay for shared presence. This page describes what the public server at openbikenet.cloud stores. If you run your own server, you decide what it stores.

What is stored

  • The app ID and versions that connect, and the dates each app was first and last seen.
  • How many riders each app had, per minute. The public statistics at /v0/stats show the last 30 days.

That is all. The counts are what makes the public usage statistics possible.

What is not stored

  • Rider names, rider values, positions, speed, power, cadence or heart rate. They are passed on to the other connections and kept only in memory while a rider is connected.
  • IP addresses. They are used only to limit connections per address and are never written to disk.
  • Cookies or analytics. This page and the landing page have neither.

How long it is kept

Per-app rider counts are stored per day. The public statistics only read the last 30 days. There is no rider history to delete, because none is kept.

Questions

Ask in the discussions, or open an issue in the server repository.
