● OpenBikeNet server

A neutral relay that lets riders of different indoor cycling apps meet on the same route.

This is a backend for apps. There is nothing to use here in a browser.

Endpoints

WS/v0Protocol v0: presence on shared routes
GET/v0/statsConnected apps, riders and usage per app
GET/healthzLiveness check

Apps using it

OpenRadlr Open-source indoor cycling in the browser. The first app on OpenBikeNet and a reference implementation of the protocol: see its client code · source, AGPL-3.0
